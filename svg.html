SVG Images

What's an SVG? A .svg (Scalable Vector Graphics) is an image file format that uses vector graphics to create images. Unlike 'raster images' (like PNGs or JPGs), which are made up of individually placed pixels, SVGs are based on mathematical expressions, allowing them to be scaled infinitely without losing any quality. SVGs also have (generally) smaller file sizes, and also supports transparency.


SVGs are most commonly used for logos, icons, and in other applications that require scalability without losing quality. They can be easily edited with certain text editors or vector graphic software, making them a versatile choice for designers.
