Other File Types

What about other file types? In addition to GIFs, SVGs, PNGs and JPGs, there are many other image formats used in digital media, each with its own strengths and weaknesses.


Some of these formats include WEBP (Web Picture format), HEIC (High Efficiency Image Coding), and AVIF (AV1 Image File Format). Each format has its own use cases, advantages, and disadvantages.


  • WEBP is a modern image format that provides superior compression and quality compared to traditional formats like JPEG & PNG. It's ideal for web use where file size is a concern, but remains mostly unsupported.
  • HEIC is a high-efficiency image format that offers better compression and quality than JPEG. It's commonly used on Apple devices and other newer flagship phones, but has limited support on other platforms, usually requiring conversion to a different file type.
  • AVIF is a newer image format that uses AV1 compression to deliver high-quality images at smaller file sizes. It is currently gaining support in modern browsers and applications.
